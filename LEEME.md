# Demo de Tornillería Oriente para argox03/Prueba

Demo compilada con datos ficticios. Cada navegador guarda sus propios cambios.
No incluye datos-exportados.zip ni requiere Firebase para probarla.

1. Extrae este ZIP.
2. En github.com/argox03/Prueba usa Upload files (o uploading an existing file si está vacío).
3. Sube TODO el contenido extraído, incluidas las carpetas assets e icons. index.html debe quedar en la raíz del repositorio, no dentro de otra carpeta.
4. Confirma con Commit changes.
5. Settings > Pages > Source: Deploy from a branch > main > /(root) > Save.
6. Espera a que Pages muestre la publicación terminada. Dirección esperada: https://argox03.github.io/Prueba/

No subas el ZIP sin extraer. No subas datos-exportados.zip.
Con GitHub Free, Pages requiere repositorio público.
Esta es una demo; no es el código fuente para desarrollo ni una versión aprobada para operaciones reales.
Compilada con VITE_MODO=demo, VITE_BASE=/Prueba/, fuentes latinas incluidas.
Para actualizarla, recompila el proyecto fuente con esa misma ruta y sustituye los archivos.
